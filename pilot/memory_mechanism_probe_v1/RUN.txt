Adjust paths if the original base model or training run lives elsewhere.
Reuse the completed training run containing config.json and adapter/; no training
or claim extraction is performed. The original NF4 base reads all four arms with
the adapter disabled. Frozen returned claims are included in packets.jsonl.

13 cases x 4 arms = 52 answer sessions, at most 26 extra lookup calls.
Arms: raw, learned_claim, reference_atomic_claim, learned_claim_with_lookup.
Reference input includes focused reference facts plus the recent raw buffer.
Lookup is model-selected from visible original record IDs. At most two rounds
and two records per round. Cumulative input is limited to 7936 tokens; each
generation has at most 256 output tokens. Budget failures remain invalid cases.
Lookup therefore costs additional compute; this is a mechanism diagnosis,
not a stage x claim causal estimate or a measured online alarm experiment.

Identical commands resume cached cases. Changed code/config needs a new --out.
Return the complete out/memory_mechanism_probe_v1/ directory, including config,
preflight, answers, initializations, summary.json and review_packets.json.

Labels are nonblind AI candidates on four project-seen authored tasks, not
independent human ground truth. Review semantic support against original records.
Historical 46-question controls are prepared but not executed by this runner.
Do not infer generalization or online failure-detection gains from this pilot.
