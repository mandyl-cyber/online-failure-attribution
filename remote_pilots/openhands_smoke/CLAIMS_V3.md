## 远程运行

在已有 qwen-local 服务可用的远程机器，从仓库根目录运行。运行器只有 Python 标准库依赖，无需修改现有 GPU 环境。

```bash
cd ~/online-failure-attribution
git pull --ff-only
python -m unittest discover -s tests -p test_stage_claim_summary.py -v
python -m remote_pilots.openhands_smoke.claims_v3 run
```

默认地址 `http://127.0.0.1:30001/v1`，模型 `qwen-local`。可通过 `--base-url`、`--model` 覆盖，并记录在实验配置。服务需由用户原有启动方式运行；本命令不启动或更换模型。

传回整个 `out/swe_claims_v3/` 文件夹即可，无需复制终端长日志。返回内容包括六个原始响应、实际请求、耗时、失败原因、冻结证据、参考要点和待填语义审核表。任一失败/超限/未决作业会返回非零退出码，但已完成结果仍保存。

重复相同命令只处理没有结果文件的作业：不自动重发 failed 或 reserved，不覆盖语义审核。reserved 表示此前可能已经发送但未完整落盘，应检查后另开明确命名的新实验，而不是删除文件假装首次运行。参数、代码或输入改变须用新的 `--out` 目录。

## 变更与边界

- 模型只输出 `text / source / evidence_ids`，去掉 objects 与六条固定上限；整体输出仍限 2048 tokens，截断不接受。
- 保留 1200 字符分块。片段嵌在父记录内，父记录归属于动作—观察单元；程序恢复原始引用范围。
- 这里使用已有转换器给出的 `source_step_id` 配对，不能直接用于任意并发事件。重复动作拒绝，缺失动作/观察显式显示；原生事件关联仍由上游适配器负责。
- 每次运行前从原始快照重建请求与引用映射，拒绝哈希不符、跨阶段证据、封口时尚不可见的证据或材料漂移。
- 当前自建服务拒绝 response_format，因此本轮明确是 **prompt_only**。未实现强约束解码，不能宣传格式保证。没有自动重试、JSON 修补或额外审核调用。
- 请求字节限制仅是资源保护，不是 token 估算。实际 token 超出服务上下文会保留 HTTP 错误，不静默裁剪。
- `ready` 仅代表结构与来源校验通过，`ready_empty` 不代表无风险。回放输出的 `available_at_seq=null`，不会伪造实时可用时间。

## 选择与评价

`pilot/swe_claims_v3/development.jsonl`：六个真实完整阶段，来自三个已有任务。覆盖计划、源码条件、编辑、验证受阻、失败后成功示例与提交。按问题覆盖选择，不是随机抽样，也不是新任务验收集。中断转向等类别仍需后续补样。

`pilot/swe_claims_v3/reference_points.json`：生成输出之前根据原始证据建立的 14 个 AI 参考要点（含 1 个辅助要点），不是人工金标，也不进入模型 prompt。每个要点带来源和候选证据块；审核实际输出时还须精确检查其所引块，不要求逐字匹配参考文本。参考列表不是所有合理摘要的穷举。

回传后按以下顺序审核：

1. 全部尝试的协议状态与原始失败，不能只统计成功子集。
2. 每条 claim 的所有关键断言是否由其所引证据支持；来源/条件/时态是否正确。
3. 参考关键要点是完整覆盖、部分覆盖、遗漏还是不可判断；支持性要点另列。
4. 严重反转（失败当成功、计划当完成、源码当执行）逐条记录；重复要点与不必要元数据也记录。
5. 输入/输出 token、耗时与失败成本一起汇总。结构合法率不能代替语义准确率。

本轮只用于定位工程与语义问题；不据六条样本宣布通过总体准确率门槛。v3 同时改变输入组织、输出字段和提示，是新的工程基线；不能从总分变化推断单项贡献。未通过复核前，不扩大到全量、不训练、不接报警。
