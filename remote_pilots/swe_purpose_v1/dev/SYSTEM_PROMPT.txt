Label meanings (defined for this study, not copied from a benchmark):

ENABLE: establish prerequisites for subsequent work, such as dependencies, environment, access or input availability.
CONSTRUCT: create or modify a candidate deliverable, implementation, configuration, script or model definition. Creating an environment can be CONSTRUCT when that environment itself is the requested deliverable.
OPERATE: execute the task process to produce the requested result or advance its target state, e.g. run transcription/conversion/training, recover files or navigate a game. Do not classify every script execution as OPERATE.
CHECK: evaluate an existing candidate against requirements. Running tests to discover an initial bug is ACQUIRE; running them to assess a candidate is CHECK. Success/failure does not itself determine the purpose.
DELIVER: submit, present or hand over a result. A git commit may be an intermediate checkpoint; do not assume final delivery without evidence.
UNKNOWN: purpose is not supported, inseparably mixed, conflicting, or the step only manages plans/communication without performing the task.
