# SWE 切分案例复核：在线对象信息与边界时机

## 本轮结论

完成 12 个诊断案例的 AI 复核，没有修改金标，没有训练新模型。检查既有实验后，暂不重复增加路径类别/重叠等对象特征：这些特征已经做过，未显示稳定总体收益。案例也不支持把“换文件”直接当作新阶段。

## 既有实验核对

- `OBJECT_EVIDENCE_EXPERIMENT.md`：路径类别、相邻对象重叠、同脚本参数变化和结果模式已经在固定 GRU 输入消融中测试。对象通道整体 D0 +0.397 点、区间跨零；SWE 有局部正向信号，Terminal 下降。不能宣称对象信息完全无用，也不能据此重复同一实验后称为新方法。
- `CONTINUITY_EXPERIMENT.md`：局部连续性辅助监督没有稳定增量，同工具内部边界仍大量漏检。
- 最近工具转换 LR 对照：F1 微升但精确率下降，不通过门槛。

## 抽样和证据范围

从现有 SWE 专用五折预测中，按 tol1 D0 最大一对一匹配找到 138 个 PLAN→READ FP、37 个 READ→READ FN。分别以 (traj_id, step_id) 的 SHA256 排序，桶内每任务/内容组最多一例，取 6 例。样本有目的地来自错误桶，不代表总体分布。

12 条来源均重新加载原始轨迹，逐步 ID 和 action/observation 内容指纹与冻结数据一致。包中保留完整局部动作与观察：前缀为截至目标步的最近四步，后续两步单列，thought 不参与复核。AI 实际阅读的摘要上限为前缀动作 1000 字符/观察头 300 字符，后续动作 700/观察头 200；不是全文语义审阅，缺少初始任务全文和更长历史，不能据此判定整个前缀都不足。

先记录前缀判断，再查看后续两步；金标位置和错误桶始终可见，因此不是盲标。`reviewed=true` 仅表示在上述范围完成 AI 复核，不是人工认证。训练标签保持不变。

## 发现

1. PLAN→READ 样本中，4/6 是初始计划后的目录列表或 git status。它们更像环境定位，工具变化本身不足以支持切分。另 1 例从目录查看转到具体文件读取，却也不是金标边界；不能把“开始读源码”设为统一硬规则。
2. `plan_read_fp_2` 的预测在 33、金标在 32。虽相距一步，D0 要求 detected_at<=gold，所以它无法匹配 32。该 FP 至少包含时机偏差问题，不应直接描述为完全多余的阶段。
3. READ→READ 中，`read_read_fn_5` 从源码读取转向 tests 目录，`read_read_fn_6` 从仓库总览转向具体实现文件，有在线可见的对象/用途线索。但类似的“总览→源码”在另一个 FP 案例中没有金标切点，作用依赖任务上下文。
4. `read_read_fn_4` 是同一 password.py 的整文件查看转局部行段。路径不变仍有金标边界；随后一步发生编辑。`read_read_fn_1` 在读 python.py 后两步发生编辑。后续信息使“准备修改”的解释更容易，但不能倒灌给当前步模型，也不能证明原标注者使用了未来信息。
5. `read_read_fn_3` 在查询 add_artist 后连续查看 Axes 与 Figure 实现，局部证据更像同一符号的连续调查；`read_read_fn_2` 的类型文件读取失败后仍在寻找文件。两例在当前证据范围内无法明确解释精确金标位置，保留 uncertain。

以上只提供诊断假设，没有边界准确率或不可预测比例。既有 PLAN 动作表示多为换行，缺少结构化任务正文；此前已做过计划字段恢复消融，本轮不把这个已知缺失包装成新发现。

## 调整后的下一步

1. 先把现有折外错误按“精确位置偏移”“邻近重复切点”“局部语义分歧”分开量化，同时报告 D0 和 D1；后者是允许一观察步延迟的在线协议，不能替代 D0 或冒充即时结果。
2. 对本轮 uncertain 案例补齐初始任务、完整当前观察及更长的历史前缀，再做不显示未来和金标的独立复核。允许继续用 AI，但不能当成人工准确率证据。
3. 如完整前缀出现稳定的对象/子目标线索，再选未被现有特征覆盖的一项做固定折对照。现在不支持重复堆“路径变化”特征或再次扩大七类标签训练。
