# SWE 前缀关系证据输入 pilot

## 目的与范围

在六条已经复核过的 SWE 错分案例上，检查有界前缀证据是否比四步结构特征更能表达目标延续。这里只验证输入，不训练模型、不修改在线默认配置，也不报告新的边界 F1。案例来自历史开发集、按错误类型选取，AI 已见过既有分析；不是独立盲测或人工金标。

## 实现

`segmenter/relation_evidence.py` 逐步读取动作、观察、工具类型、退出码及部署可见的公开计划。只处理当前及之前的数据，忽略 thought、gold、future 字段。返回独立快照，强制步号递增。记录最多最近 32 步内的 8 个失败候选、一次工具确认编辑、32 个计划项；文本截断，路径只做词法匹配。零测试单列，其他命令成功不会清除旧失败，完全同命令成功重试才清除其失败。

READ/SEARCH 输出中的异常文本不作为执行失败。真实命令被上游错分为 READ 时仍可能漏检。只识别部分工具编辑回执；路径别名、不同命令消除失败、截断掉的关键信息都尚未解决。

生成器保留原结构特征作为并排对照。answer_key 仅用于取相同轨迹的缓存特征，不传给关系构建器；公开计划来自此前核对过 action ID 的前缀包。没有执行数据集内任何命令。

## 逐例结果

| 案例 | 输入效果 | 判断 |
|---|---|---|
| 01 | 将 35/36 测试失败或零测试与 37 读取同一入口关联 | 有用的延续候选，不是同一目标证明 |
| 02 | 保留计划切换，遗漏此前成功测试的语义证据 | 证据不完整 |
| 03 | 保留导入失败与验证完成声明；声明本身承认阻塞 | 共现不代表矛盾 |
| 04 | 运行测试以观察失败被标记完成，同时存在失败 | 候选误报；失败可能是目标的一部分 |
| 05 | 失败后 git status，无法判断排查还是收尾 | 应保持无法判断 |
| 06 | 保留首次测试尝试失败，但遗漏此前查找入口动作 | 尚不能表达目标转换 |

`declaration_evidence_tension_candidate.present` 仅表示完成测试类计划与近期失败共现，不是已验证的矛盾。`purpose_relation` 固定为 undetermined、`boundary_decision` 为 null。六例 AI 复核在 `pilot/swe_relation_input_v1/ai_review.json`，禁止直接作为训练标签。

## 验证及结论

6 个单元测试通过，覆盖零测试、词法关联、成功重试、公开计划、失败编辑、隐藏字段隔离、历史快照、有界记忆以及读文件中的异常文本。生成器输出六例配对输入。没有测量此模块真实线上延迟，不能拿旧结构模型耗时替代。

当前结论：值得保留证据候选原型，但不足以开始下一版训练。尤其“失败记忆”偏向负面观察，不能单独承担工作目标建模。此前对象证据、计划字段和连续性实验没有稳定收益，本次小样本不推翻这些结果。

## 下一步门槛

1. 同时保留短历史中的成功动作与失败动作，保存命令/文件/公开计划的来源步号；公开计划完成不等于执行成功。
2. 扩大输入复核，包含正确切点、正确不切、误切和漏切；先冻结抽样规则。标注关系证据是否支持结论，并允许无法判断，不把工具类别变更自动标为新阶段。
3. 若信息增量明确，再在原任务分组协议下对照结构基线、结构加关系特征。主指标即时 ±1 F1，同时报告精确率、切点数、逐任务配对区间和开销。既有数据只能称开发验证；独立新任务结果另报。
4. 未获得稳定收益前保持现有结构模型旁路，不改默认划分器、不增加每步 LLM 调用。下一步本地 CPU 可完成，无需远程 GPU。

复现：
```powershell
python -m unittest discover -s tests -p test_relation_evidence.py
python -m remote_pilots.openhands_smoke.build_relation_pilot
```
