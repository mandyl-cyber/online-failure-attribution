# SWE 切分对账本的影响：本地结构对照与远程准备

## 已有能力核对

仓库已有 `experiment_ledger_partition.py`，使用旧阶段策略预测及规则复制后端，主要测预算和引用覆盖；不是当前 SWE LR 与规则三组语义对照。`prepare_downstream.py` 可准备 CodeTracer 金标/规则成对输入，但准备输入不等于已完成模型归因。当前 claim 抽取契约明确不推断根因或图边。

本轮采用当前 SWE OOF LR、缓存修复后规则在线边界、原金标三组，固定上一轮 16 个任务（非独立、非代表性样本）。每个阶段结束组装一次作业，单阶段多 claim。只改变分组，原动作和观察在分组前生成相同证据记录；无 thought、错误步标签或未来步骤。

## 本地结果

每作业输入上限 64000 字节，每轨迹每组累计请求上限 512000 字节，每作业至多 64 条观察摘录候选。超预算拒绝，不截断阶段。规则后端复制观察摘录，不能评估语义。

| 切分 | 阶段数 | 接受作业 | 失败作业 | 被引用观察 / 可用观察 | 重复引用 |
|---|---:|---:|---:|---:|---:|
| 金标 | 94 | 85 | 9 | 487 / 595 | 0 |
| 结构 LR | 113 | 103 | 10 | 439 / 595 | 0 |
| 规则 | 123 | 113 | 10 | 421 / 595 | 0 |

对应覆盖约 81.85%、73.78%、70.76%。这表明固定预算下分组会影响证据被接收和引用的范围，不表明金标 claim 语义更准确。相同上限也不代表实际调用数和总成本相同。不同步骤的观察文字可以重复，文本重复数不等于重复事实或重复 claim。

这是回顾性阶段分组敏感性检查：规则的原 detected_at 时间未用于模拟作业封口，不能宣称复现真实队列延迟。源轨迹哈希和步号核对通过。归因准确率、语义遗漏和跨阶段依赖均尚未评估。

## 远程输入

从同一固定集合中按轨迹 ID SHA256 排序，选前三条长度不超过 40 步的任务；不按成功率、金标或本地覆盖选样。三组共 51 个作业，其中 3 个预检超预算，48 个请求可执行。全部错误保留在 manifest，不从分母消失。

远程去掉规则候选提示，要求 Qwen 直接从相同阶段内的原动作/观察抽取 claim；三组都不提供任务文本或先前账本，以隔离本阶段分组影响。这是最小阶段抽取对照，不是最终带上下文的账本系统。组别只在评估 manifest 中，不发给模型；stage 内容本身当然随切分不同。

模型 `qwen-local`，temperature=0，每请求最多输出 2048 token、一次尝试、单并发，48 次最多请求 98304 个输出 token。输入字节限制不是 tokenizer 限制；服务端上下文超限会计失败，客户端不静默截断。使用已经跑通的本地 Qwen 服务即可，无额外硬件需求。

运行器只用 Python 标准库，支持断点续跑。输入及运行器哈希固定；每次调用前写 reservation，防止进程中断后重复调用。残留 reserved 表示不确定尝试，不能当成功或自动重试。输出保留原始模型响应、格式/引用校验错误及调用耗时。`valid` 仅表示字段和精确引用合法，不能证明语义正确。

## 运行

远程仓库根目录：
```bash
git pull --ff-only
python remote_pilots/openhands_smoke/run_ledger_sensitivity.py
```

确保之前的 Qwen 服务仍在 `http://127.0.0.1:30001/v1`。运行器先检查 models 端点；若不可达会在发起任务前停止。无需启动 OpenHands 或 Docker 任务。

结果位于 `out/swe_ledger_sensitivity_v1/`。完成后回传整个目录；可打包：
```bash
tar -czf swe-ledger-sensitivity-results.tar.gz -C out swe_ledger_sensitivity_v1
```

如果 `git pull --ff-only` 失败先保留本地改动，不要 reset。运行命令可以重复用于继续未尝试作业；failed/reserved 作业不会自动重跑。

## 验证及后续

远程契约的 5 个本地测试通过：合法 Unicode 引用、空 claims、非法 span/布尔索引、额外字段、错误引用、重复 ID、外来证据与 observation 类型约束。没有从本机调用远程 Qwen，实际模型兼容性和输出质量待回传确认。

回传后先统计三组失败、有效引用和证据覆盖，再做固定案例 AI 语义核验，分开报告“遗漏事实”“文本重复”“无证据断言”。没有语义金标时不能把这些统计包装成真实准确率。跨阶段依赖和最终归因还需要单独的账本上下文及归因协议，本轮未实现或声称完成。

输入及结果：`pilot/swe_ledger_sensitivity_v1/`；远程入口：`remote_pilots/openhands_smoke/run_ledger_sensitivity.py`。
