# SWE 边界错误分析及工具转换单特征对照

## 决策

不替换当前模型。单个“前一步工具类别 → 当前工具类别”交互特征使即时 ±1 F1 上升 0.35 个百分点，但精确率下降，任务组配对 95% 区间跨零。当前线上 SWE 冻结模型和默认规则均未修改。

## 错误分析

从现有 SWE 专用模型的五折测试预测出发，以最大一对一、容差 ±1、即时 D0 匹配划分 TP/FP/FN。总计 837 TP、857 FP、525 FN。部分高频转换：

| 转换 | 命中 TP | 误切 FP | 漏切 FN |
|---|---:|---:|---:|
| PLAN → READ | 105 | 138 | 24 |
| PLAN → VERIFY | 52 | 88 | 9 |
| EXEC_WRITE → PLAN | 37 | 63 | 27 |
| READ → SEARCH | 4 | 31 | 44 |
| SEARCH → READ | 2 | 14 | 40 |
| READ → READ | 0 | 0 | 37 |

这些是错误数量，不是各转换的条件错误率。匹配允许一步容差，TP 的转换按预测步归类，FN 按金标步归类，不能直接把 TP/(TP+FN) 当作该转换的召回率。邻近重复预测还可能因一对一匹配而归为 FP，不能仅据这些数字判定语义错误。

初步判断：计划附近的步骤变化容易触发误切，探索内部也存在漏切；简单把类别变化当成阶段变化不成立。下一步的语义解释需要查原动作和观察，而不是直接把统计类别当作人工认定的原因。

## 单变量实验

保留四步结构 LR、C=1、无文本编码器；仅添加一个类别交互特征 `lag0:tool_transition`，由已有 lag1/lag0 工具类别组成，不读取未来步骤、thought 或阶段金标。

使用既有 SWE 276 条轨迹的五个任务/内容分组折。每轮三折训练、下一折开发选阈值、剩余一折测试。模型及阈值网格沿用原协议，拟合前将协议写入 `protocol.json`。未进行多版本搜索。

| 指标 | 原 SWE 结构模型 | 加转换特征 |
|---|---:|---:|
| 即时 ±1 F1 | 0.547775 | 0.551270 |
| 精确率 | 0.494097 | 0.481117 |
| 召回率 | 0.614537 | 0.645374 |
| 精确位置 D0 F1 | 0.482330 | 0.490436 |
| 预测切点 | 1694 | 1827 |
| ±1 D0 命中 | 837 | 879 |
| ±1 D0 误切 | 857 | 948 |
| ±1 D0 漏切 | 525 | 483 |

配对任务组 bootstrap 1000 次：F1 差 +0.3495 个百分点，95% 区间 [-1.0045, 1.6333] 个百分点。多预测 133 个切点，多命中 42 个，误切增加 91 个。PLAN→READ 的误切由 138 增至 170，未解决主要误切来源。

这是历史开发语料上的探索性对照；查看既有错误后选特征，因此不能称为全新盲测结果。单次训练加冻结模型条件下的 bootstrap 不包括重训练不确定性。该特征没有获得上线资格，也没有证明语义划分问题已解决。

## 下一步建议

优先逐案检查 PLAN→READ 的误切与 READ→READ 的漏切，记录是否为同一文件/对象上的延续、是否发生子目标变化、金标边界是否依赖后续信息。可由 AI 辅助复核，但应明确不是人工准确率验证。随后只选一种能从在线前缀计算的对象连续性特征做新对照，先核对已有 object-evidence/continuity 实验，避免重复旧实验。暂不扩大七类目的标注，不继续堆工具类别交互。
