# 固定 SWE 预测：D0/D1 时机与匹配竞争分解

## 结论

SWE 专用结构 LR 的即时 ±1 边界 F1 为 0.5478，允许晚一步的 D1 为 0.6041。预测和阈值未改变，后者只是不同评分口径，不能宣称模型提升或已经实现“一步延迟确认”算法。

位置/时机偏差解释部分错误，但不是主要瓶颈：D0 未匹配预测中 64.6% 位于所有金标 ±1 步范围之外；漏检金标中 79.4% 在 ±1 步内没有任何预测。无法仅靠等待一步或去除重复切点解决。

## 协议和类别

276 条 SWE 轨迹、1,362 个金标边界，使用既有任务分组折外预测，不重训、不调整阈值。不使用全量拟合部署模型回测训练集。

预测位置为 b，发出时刻为 t，金标位置为 g。空间容差固定 |b−g|≤1；D0 额外要求 t≤g，D1 要求 t≤g+1。每个预测和金标最多匹配一次，以最大匹配计算 TP，所有晚预测仍留在精确率分母中。

对每个口径单独匹配，再将未匹配项按互斥规则分类：

- `outside_tolerance`：预测周围 ±1 步没有任何金标。
- `timing_only`：空间上有候选，但均不满足该口径的发出时刻要求。放宽时机后也未必命中，因为可能与其他预测竞争。
- `competition`：存在空间与时机均合法的候选，但在最大一对一匹配中名额被占用。不能直接称为语义上多余的 stage，也不能据此把全部邻近预测去重。
- 金标侧 `no_nearby_prediction`：附近没有任何预测；其余按时机或竞争分组。

没有金标的轨迹使用单独 no_gold 类。本次 SWE 结构结果未出现该类。剩余项目只表示需要语义复核，不判定金标错误。

改用 D1 后，未匹配预测为 554 个空间外项目和 217 个竞争项目；漏检为 417 个无邻近预测和 22 个竞争项目。净增命中 **86**，不是 217。最大匹配会重新分配配对，不能把独立两次匹配的具体 ID 差简单解释为逐个“救回”。

报告同时保存匹配位置偏移直方图，但该最大匹配没有“优先精确位置”的次级优化。直方图中的 offset=0 数量不等于独立精确位置评分的 TP，不能用来声称模型准确切中某位置的总次数。

## 已完成检查与限制

四个测试通过：晚一步及远距离预测、多预测竞争、放宽条件后的重新匹配、无金标与延迟发出。每条轨迹及全量计数均检查 FP/FN 分解与统一评分器一致，输入记录 SHA256。

这是历史开发语料上的诊断；没有新增任务盲测、没有人工语义复核。D1 仍可对应在线协议，但其一步是工具动作/观察步，不是固定毫秒数；对于长工具调用，时延成本可能大。
